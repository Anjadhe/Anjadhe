# nenva

Releases of **nenva**, the personal AI whose data lives on your Mac.

- Download the latest version from [nenva.co/download](https://nenva.co/download).
- Every version is under [Releases](https://github.com/Anjadhe/nenva/releases); the app updates itself from here.
- `remote-config.json` is the signed configuration the app reads at launch.

The source code is not published. Questions: [support@anjadhe.ai](mailto:support@anjadhe.ai).
