# v0.1.0-alpha.40

Email analysis now paces itself on Anjadhe Cloud so a fresh account
connect no longer trips the service's rate limit, and the app launcher
gets a cleaner "More apps" page with a leaner default set of apps.

## Added

- **More apps page.** The launcher's on/off surface is now one card per
  app — icon, name, a one-line description, and a switch. Reached from
  the sidebar's "More apps" row, the app switcher, and Settings ›
  Appearance. Turning an app off only hides it from the launcher: its
  data stays, and Cmd+K still finds it by name.
- **A leaner default.** Wellness, Web Browser, AI Activity, Help, and
  About start switched off on new installs; one click on the More apps
  page brings any of them back — and the choice sticks.

## Changed

- **Bookmarks live inside the Web Browser.** Every new tab shows your
  bookmarks, and its "Manage" button opens the full Bookmarks page.
- **The Actions app reads "Tasks"** in breadcrumbs and help — the same
  app, named for what it holds.
- **The home feed's welcome post now explains routines** — what they
  are, the ready-made ones, and how to create your own by asking the
  assistant.

## Fixed

- **Connecting an email account no longer trips Anjadhe Cloud's rate
  limit.** Insight analysis spaces its requests out on a cloud model,
  and when the service does ask it to slow down, every part of Email AI
  — insights, reservation details, thread judgments, inbox bundles —
  waits and retries instead of skipping mail. Before this, a burst of
  429s could park thread judgment and bundling for the whole session
  and silently cost a booking its reservation facts.
- **Tasks list dates line up.** A long date label ("Annually (Dec 13)")
  widened its own row's date column, pushing that row's title out of
  line with the rest.
- **Blank-slate test instances no longer see real documents.**
  `ANJADHE_DATA_ROOT` now also redirects the `~/Anjadhe/` content tree
  (library, user apps, artifacts).
