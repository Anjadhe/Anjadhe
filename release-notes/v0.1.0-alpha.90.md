# v0.1.0-alpha.90

## Added

- **Run now from a routine's result.** A routine's result page has a Run now
  button beside the routine's name. A routine that runs on this Mac runs in
  place and the page turns to the new result.

## Fixed

- **A routine could post a tool request instead of an answer.** When a run
  reached its tool limit, the model sometimes wrote out one more tool request
  as text, and that text was posted to the feed as the result. It is never
  shown now: the model is asked once more for a plain answer, and if none
  comes the routine says it reached its limit.
