# v0.1.0-alpha.124

A fix for new repeating commitments.

## Fixed

- **A new repeating commitment no longer asks about days before you made
  it.** A weekly commitment made on a Friday for Saturdays was asked about
  on Now ("Not marked Sat, Oct 3. Did you do it?") about the Saturday
  before it existed. A repeat with no start date now begins the day you
  made it, so its first day is the next one that comes.
