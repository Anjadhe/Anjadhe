# v0.1.0-alpha.38

Anjadhe Cloud grows a model choice: the service can offer several
hosted models, and you pick which ones to add.

## Added

- **Choose your Anjadhe Cloud model.** Add model › Anjadhe Cloud now
  lists the models the service offers — each with a name and a
  one-line description — instead of a single fixed entry. Every pick
  becomes its own entry in Your Models, so cloud models sit side by
  side with local ones and switch from the model chip like anything
  else. The lineup comes from the server's own catalog, so new
  models can be offered (or swapped for better weights) without an
  app update; if the catalog is unreachable the step falls back to
  the original single model.

## Changed

- **Cloud model names follow the server.** If a hosted model is
  renamed in the service catalog, existing installs pick up the new
  name at next launch — on the model chip, the Settings cards, and
  feed post bylines.
- **The Anjadhe Cloud Manage panel names the server it talks to** —
  normally api.anjadhe.com, and explicitly marked when a test run
  overrides it.
