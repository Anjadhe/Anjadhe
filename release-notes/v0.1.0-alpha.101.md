# v0.1.0-alpha.101

## Changed

- **The local AI engine updates itself.** nenva local now runs on a newer
  llama.cpp build, and replies come about 10% faster. Like the app, the
  engine updates by itself in the background without stopping anything you
  are doing, and the next time the model loads it uses the new build. If an
  update ever fails, the previous engine keeps working and
  **Settings › AI Assistant › Models** offers **Try again**.

## Fixed

- **Switching to nenva local for the first time works.** New installs
  start on nenva cloud, and picking nenva local used to switch right away,
  so the first chat failed while the model was still downloading. Now the
  engine installs and the model downloads first, your current model keeps
  answering, and nenva local takes over when the download finishes.
