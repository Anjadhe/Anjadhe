# v0.1.0-alpha.43

Notes editor fixes and a close-window guard for running AI work.

## Added

- **Markdown pastes as formatting.** Text copied from a `.md` file lands in
  a note as real headings, lists, quotes, code blocks, rules and
  bold/italic/links, not as source with `#` and `**` in it.
- **Normal text** in the note editor: a `T` button on the selection
  toolbar, a "Text" item in the `/` menu, and Cmd+Shift+0 turn any
  heading, quote or code block back into a plain paragraph and strip
  inline formatting.

## Changed

- **Closing the app asks when AI work is running.** Closing the window,
  Cmd+Q and Force Reload now show the same kind of warning Cmd+R already
  did, naming what would stop (an assistant reply, a task run, a build).
  Stay to keep working, Leave to go anyway. Ambient email analysis, which
  resumes on its own, still never prompts.

## Fixed

- Pasting several lines of plain text into a heading no longer turns the
  whole paste into one giant heading; each line becomes its own paragraph.
