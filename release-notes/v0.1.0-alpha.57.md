# v0.1.0-alpha.57

## Added

- **Claim your free alpha license.** Everyone who installed during the
  alpha keeps Anjadhe free for good, and now that promise is a key you
  hold: a small signed license saved on your Mac, verified there with a
  public key, no account. Claim it from the Home checklist, the one-time
  prompt, About › Closed Alpha, or Settings › License. It asks for an
  email address only so the same key can be issued to you again on
  another Mac or after a reinstall; that address is the only thing sent.
- **Settings › License.** Shows the license this Mac holds (class, when
  it was issued, how long updates run), takes a pasted key or a license
  file, and can forget the key on this Mac. A license never locks a
  feature; it decides which releases the updater may install once the
  alpha closes. Nothing changes for anyone until that date is announced.
- **Get this Mac's reminders as iMessages.** Settings › Accounts ›
  iMessage sends reminders and alerts to your own iMessage through the
  Messages app on this Mac — a text from you to you, Apple end-to-end,
  no bot or server in between. One-way: the assistant never reads your
  messages.
- The assistant can now answer "what does Anjadhe cost?" and "how do I
  claim my license?" from a new License help article.

## Changed

- **The iPhone app is native SwiftUI.** The phone's screens, navigation
  and settings are now Swift; the web view remains only as the hidden
  sync engine. Same pairing, same encrypted channel, same Mac brain.
- The titlebar update pill can now say why a newer build was not
  fetched ("needs a license" / "updates ended") and opens Settings ›
  License. Today every install passes, so you will not see it yet.
