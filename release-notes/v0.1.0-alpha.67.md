# v0.1.0-alpha.67

## Fixed

- **Apple Calendar and Apple Reminders now actually ask for permission.**
  alpha.65 added the usage descriptions and still never prompted. The
  real gate was the app's hardened runtime: without the calendars
  entitlement, macOS refuses calendar and reminder access silently, with
  no consent dialog and no Anjadhe row under Privacy & Security. The
  entitlement is in place, so turning on Apple Calendar or Apple
  Reminders shows the dialog.
