# v0.1.0-alpha.59

## Added

- **Telegram has its own help guide.** Ask the assistant "how do I set
  up Telegram?" and it answers from a step-by-step walkthrough: create
  your bot with @BotFather, connect the token, link one chat with the
  pairing code, switch it on, forward reminders there, and how to unlink
  or disconnect. The same guide is on anjadhe.ai/help.

## Fixed

- The assistant's built-in guide could not open the License topic added
  in alpha.58, nor the new Telegram one; both are reachable now.
