# v0.1.0-alpha.97

## Changed

- **Stock profiles are rewritten when you open them, not every day.**
  Portfolio used to rewrite the AI business profile for every stock you
  hold or watch once a day, which meant many long model calls for stocks
  you never looked at. Now each stock gets its first profile on its own,
  and after that a profile is rewritten only when you open that stock, or
  ask the assistant about it, on a later day. Until then the page and the
  Tickers table show the last profile with the day it was written.
