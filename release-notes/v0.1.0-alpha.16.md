# v0.1.0-alpha.16

## Added

- **Starter prompts out of the box** — every install now comes with four
  scheduled background prompts: Daily Briefing (your tasks and calendar each
  morning), News Digest, Daily Motivation, and Weekly Reflection. They're
  ordinary prompts — edit, reschedule, or delete them on the Prompts page.
- **Email insights on the home feed** — unread insights (renewals, bills,
  appointments) appear as feed cards alongside prompt results. The × marks one
  read; clicking opens its new detail page.
- **Insight detail page** — clicking an insight (in Email → AI Insights or on
  the home feed) opens a full page: summary, action items linked to their
  tasks, feedback buttons, and the underlying email. Opening marks it read.
- **Feed preferences** — the sliders button in the feed header chooses what
  the feed shows: prompt results, email insights, and whether read insights
  stay hidden.
- **Per-page help** — every feature page has a small **?** in its header that
  opens that page's guide in place; it also shows itself once on your first
  visit. New Help articles for Browse and AI Activity.

## Changed

- **Bookmarks open in the built-in browser** — clicking a bookmark opens the
  page directly (with a "Back to Bookmarks" strip); the *i* button on a card
  opens its details.
- **Notes inherit the selected tag** — a note created inside a tag-filtered
  list picks up that tag (visible as a removable pill), so it no longer
  vanishes from the list it was created in.
- **"Run now" queues instead of bouncing** — a prompt run clicked while
  another run is in progress waits its turn and runs next, in click order.
- **AI Activity tells the truth** — background prompt runs that use your
  personal context now show as "Background prompt · automatic" (they used to
  masquerade as "Assistant chat" at interactive priority), and the status line
  distinguishes running from waiting ("1 AI task running, 2 waiting").
- **Visible self-repair** — when the assistant retries a defective answer
  (empty response, promised-but-unrun tool), the chat shows a "↻ automatic
  retry" step chip, and the internal retry nudges identify themselves so the
  model's thinking no longer narrates a message you never sent.
- **Friendlier failure cards** — a failed background-prompt run posts a quiet
  status note ("The model came up empty this time — it will try again…")
  instead of a red engine error; empty responses are retried once first.

## Fixed

- **Server/cloud API key reached only chat** — email insights, bundling,
  compose, goal updates, memory, task mode, Maker, and background prompts now
  carry the default model entry's API key; they used to fail with
  "Invalid api key" on a server or cloud brain while chat worked.
- **Double app initialization** — navigating to an app re-ran its init a
  second time via the app's own URL-hash write; self-caused hash changes are
  now ignored (browser back/forward still works).
- **Scheduled prompts with no model** — the scheduler now skips quietly until
  a model is selected instead of posting an error card per prompt.
- Help/settings header buttons sized to match their sibling buttons.
