# v0.1.0-alpha.129

## Added

- **A decision model helps place mail and texts into threads.** On nenva
  cloud, the two narrow questions nenva asks while filing, "does this item
  belong to this thread?" and "are this folder and this message the same
  thing?", go to a small model built for yes-or-no judgments
  (Microsoft-Decision-1, reached through nenva Connect under a zero-retention
  agreement) and come back as a calibrated same / different / inconclusive.
  A confident answer is final; an inconclusive one defers the item or asks the
  usual check. Every join from mail into a one-company thread is also verified
  this way, so a confident mistake is sent back before it lands. Local, your
  own server, OpenAI and Anthropic setups keep their existing checks. Screened
  live on synthetic sets and on the Threads demo's week with zero wrong joins
  and zero wrong refusals; nenva Connect turns it on per question.
- **Every decision is on your Mac's ledger.** Settings › Advanced › Developer
  › Data activity lists each one as "Small jobs" or "Mail and texts", like any
  other request that left this Mac.

## Changed

- A decision that nenva Connect reports as unusable (the provider answered
  badly, timed out, or the answer was lost) is never asked again for that
  item; the usual check runs instead. Lost answers are settled from Connect's
  accounting after launch and daily, by request id only.
