# v0.1.0-alpha.41

First-run welcome pages across the apps, and task runs that pace
themselves on Anjadhe Cloud instead of tripping its rate limits.

## Added

- **Apps greet you now.** An app you haven't set up yet opens on a short
  welcome — what it does, what connecting gets you, and the door in —
  instead of an empty pane. Email, Calendar, Journal, News, Notes,
  Portfolio, Reader, and Writing Voices all have one.
- **Quick-start suggestions on Home.** A few prompt pills under the
  composer suggest things worth asking; the set stays put all day, so it
  can be used by muscle memory.

## Changed

- The app's website links (Terms, Privacy Policy, help) point at
  **anjadhe.ai**, the public domain.

## Fixed

- **Task runs no longer rate-limit themselves on Anjadhe Cloud.** The
  task engine paces its calls on a metered brain and, when the service
  asks it to slow down, waits exactly as long as asked and retries —
  no more runs dying mid-step over finished work.
- **Truthful task reports.** When a run consolidates per-item work into
  one deliverable (say, "write the document" planned as per-item edits),
  the items now settle as "unverified" instead of the whole step reading
  failed over completed work.
- **No more "No models installed" banner over a working cloud model.**
  The local-engine setup nudges no longer apply to remote engines.
- **The assistant acts instead of narrating.** "Save that" or "reschedule
  the plan" now performs the action rather than announcing it and
  stopping.
