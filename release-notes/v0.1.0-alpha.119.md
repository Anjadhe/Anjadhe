# v0.1.0-alpha.119

nenva local is now for Macs with 32 GB of memory or more.

## Changed

- **nenva local starts at 32 GB.** The small model for 8 to 16 GB Macs is
  no longer offered for download, because a model that small does not do
  the assistant's work well. On a Mac with less memory nenva runs on nenva
  cloud. If you already downloaded the small model, it keeps working.
