# v0.1.0-alpha.51

The assistant can read your journal.

## Fixed

- **"Read my journal entry" finds it now.** Asking the assistant about an
  entry written today came back empty: the Journal app stamps entries
  with a full timestamp, and the assistant's date filter compared it
  against a plain day, so the newest day of any range was silently
  dropped. Dates are now matched on your local day, and entries list
  newest first so a recent one is never hidden behind old ones.
- **The assistant can read a whole entry.** It used to see only the first
  200 characters of each entry and had no way to open one. A new
  `get_journal_entry` tool reads the full text (paged, like notes), so
  "read what I wrote and suggest something" works on the actual writing.
  Background routines are held to the same Cloud Privacy rule as before:
  Journal stays on this Mac unless you switch it on.
- **Orphaned embedding servers are cleaned up.** A session that ended
  without a clean quit (force quit, crash) could leave a ~0.5 GB
  `llama-server` parked on a side port for days, and each new session
  stepped around it instead of reclaiming it. Anjadhe now sweeps those at
  startup and before starting its own, touching only processes that
  answer like a llama-server.
