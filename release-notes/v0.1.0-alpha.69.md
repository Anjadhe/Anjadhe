# v0.1.0-alpha.69

## Added

- **Apple Calendar events can be changed from Anjadhe.** New events can
  go into any of this Mac's iCloud or local calendars (pick it in the
  form's Account row), and editing or deleting an Apple event writes to
  Apple Calendar on this Mac, with the same this-event / all-events
  choice for a repeating series. Apple stays the source of truth: every
  change is written to Apple Calendar and read straight back, so Anjadhe
  never holds an edit your calendar does not. Calendars that refuse
  edits, such as subscribed or holiday calendars, show their events
  without Edit or Delete. The assistant can create, update and delete
  Apple events too: name the calendar, or say "apple" when there is one.
- **The Apple Calendar mirror refreshes when you come back.** Switching
  back to Anjadhe from Calendar.app now updates the grid at once, on top
  of the timer added in alpha.66.

## Changed

- Reminders and Notes stay one-way imports. Reminders needs a two-way
  merge rule before edits can flow back; Apple Notes has no interface
  that survives a round trip.
