# v0.1.0-alpha.117

Calmer connector pages, and Slack steps back while it is finished.

## Changed

- **Linear and Notion pages are simpler.** Each shows its state once, has
  one main action and Disconnect set apart, with one line about privacy
  and a link to the Privacy page.
- **Slack is hidden for now.** The Slack connector and Slack monitoring
  are not ready, so they are off until a later release. A Slack server you
  added yourself under Tool Servers keeps working.
- **Portfolio headlines point you to the story.** Headlines come from
  CNBC's published feeds. A summary is two or three sentences, with "Read
  the full article" right under it.

## Fixed

- **A tool server that refuses to connect says why.** Settings shows the
  server's own reason instead of a generic error.
