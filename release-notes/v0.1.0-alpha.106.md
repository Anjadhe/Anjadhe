# v0.1.0-alpha.106

## Added

- **nenva cloud lite reads images.** Attach a photo or a screenshot in
  chat and nenva cloud lite can look at it, and Documents can read PDF
  and scan pages as images for a more accurate transcription. Settings ›
  AI Assistant › Models shows **Reads images** on the models that can.

## Fixed

- **A clear message when a model can't read images.** Sending an image to
  a nenva cloud model that can't read it now says so, instead of "AI
  request failed".
