# v0.1.0-alpha.87

## Changed

- **Your files moved to the nenva folder.** Notes, Journal, Documents and
  your own apps now live in `~/nenva` in your home folder. On an existing
  Mac the app moves the `Anjadhe` folder there once, the first time it
  opens: it is renamed, nothing is copied or deleted, and an `Anjadhe` link
  is left in its place, so an Obsidian vault, a coding agent or a Finder
  favourite that points at the old folder keeps working. If the folder
  can't be moved (for example you already have a folder called `nenva`, or
  you pointed `Anjadhe` at another drive yourself), nothing moves and the
  app keeps using `Anjadhe`.

## Fixed

- **Model names still said Anjadhe Cloud.** A cloud model you added before
  the rename kept the name it was added with. It now reads nenva Cloud.
- **The Google sign-in page showed the name in capitals.** It now reads
  nenva.
