# v0.1.0-alpha.37

A small release: routines ride out AI outages instead of skipping a
day, and an Email AI insight shows the message it came from.

## Changed

- **Routines retry through an AI outage.** A scheduled digest whose
  run fails because the model is unreachable used to post an error
  card and give up until the next scheduled day. The card still
  posts, but the run now stays queued on a backoff ladder (15 min,
  30 min, then hourly, about six hours of cover) until it succeeds
  or a newer scheduled run supersedes it. Configuring a model
  immediately retries whatever is waiting, and a successful post
  folds the error card away.
- **Email AI shows the source message.** Opening an insight now
  renders the full original email below the insight detail, with the
  same sanitized treatment as the Inbox viewer, so the summary can
  be checked against the mail itself.

## Fixed

- **Disk space is reported correctly.** macOS `df` output for the
  sealed system volume shows the OS-only Used/Capacity columns
  (~3% used on a nearly full disk), and the assistant could invert
  that into "97% available". The true free percentage is now
  computed from the real numbers and attached to the result.
