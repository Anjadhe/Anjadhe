# v0.1.0-alpha.114

A repeating task's missed day no longer disappears, and the iPhone app can
pair with this Mac.

## Added

- **Paired devices are on.** Settings › Advanced › Paired Devices pairs the
  nenva iPhone app with this Mac.

## Fixed

- **A repeating task's day you didn't mark stays on Now** until you answer
  it: "Not marked Tue, Oct 6. Did you do it?" with Mark done and Skipped,
  each for that day (with Undo). It goes when the task's next day comes, so
  a daily habit never piles up. Before, a weekly task left unmarked simply
  vanished until the next week.
