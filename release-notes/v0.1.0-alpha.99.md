# v0.1.0-alpha.99

## Changed

- **Models are named by tier, never by model.** nenva's own models now
  have tier names that stay put while the models underneath improve:
  - **nenva cloud lite**: hosted, fast, for everyday questions and
    background work (the default for a new install)
  - **nenva cloud pro**: hosted, a bigger model for harder questions
  - **nenva local**: whatever model you downloaded to run on this Mac.
    The download list tells the sizes apart by memory needed, download
    size and whether it reads images.

  A server you run yourself and OpenAI or Anthropic models you added with
  your own key keep their real names.
- **Existing setups move over on their own.** A nenva cloud model you
  already use switches to its tier name and id at first launch, on the
  Mac and on the iPhone; past answers, routine posts, Portfolio notes and
  AI Activity show the new names too.
- **"nenva cloud" is lowercase**, like the rest of the name.
- **Credits.** Settings › About names the open-weight model families
  nenva cloud and nenva local may run, under their own licenses.
