# v0.1.0-alpha.50

The News page reads like a social feed.

## Changed

- **News is a timeline now.** The front-page layout (lead story, Latest
  rail, a section per topic) became one chronological feed: every headline
  is a post with the publisher's icon, the source and the story's age on a
  byline, the headline as the post text, and the "For you" reason when
  ranking has one. Topic pages, search results and Saved wear the same
  post shape, so every list is the same feed, filtered. Headlines are
  still quoted straight from news feeds — no AI writes them.
- **Topics are tags.** Each post carries its topic as a small clickable
  tag that opens that topic's feed — the same drill-in as the topics rail.
- **Publisher avatars.** The news feed names the publisher's site, so
  posts now show the publisher's favicon in the avatar circle (the
  source's initial stands in until the icon loads, or when it can't).
  Icons load from the same favicon service Bookmarks already uses. On the
  Anjadhe Connect news route the icons appear once Connect v1.7.0 is
  live, released alongside this version.
