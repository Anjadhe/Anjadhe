# v0.1.0-alpha.115

Slack monitoring arrives, Lock nenva covers your iPhone too, and nenva's
server has a new address.

## Added

- **Slack monitoring.** Once Slack is connected, Settings › Connectors ›
  Slack › Set up monitoring picks the conversations to watch and the model
  that reads them. nenva looks for requests that need you, commitments and
  changed decisions, with optional morning reviews. Pause or stop it from
  the same page.
- **Lock nenva on the iPhone.** One switch now locks both the Mac and the
  paired iPhone app. On the phone it unlocks with Face ID, and changing the
  switch there asks for Face ID first.
- **Memory on the iPhone.** Each Memory heading opens a page where you can
  add, edit, star or remove facts, and the Mac picks up the changes.

## Changed

- **Slack sign-in returns through nenva's server** to this Mac. Your tokens
  still come straight from Slack and stay on this Mac.
- **nenva's server is now api.nenva.co** (search, nenva cloud, the iPhone
  relay, feedback). The old address keeps working.
- On the iPhone, a Now card's title opens the thing it is about.

## Fixed

- **Cards on Now no longer vanish after a reload.** A reload that ran
  before your data had loaded could set every card aside for good.
