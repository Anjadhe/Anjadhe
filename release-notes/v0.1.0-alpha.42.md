# v0.1.0-alpha.42

Cloud privacy: when the model runs off your Mac, you can see exactly what
left, decide what background work may send, and check the server.

## Added

- **"Left this Mac" ledger.** Settings › AI Assistant › LLM Logs filters
  to every request that went to Anjadhe Cloud, your own API key or your
  server, with its destination and the exact messages it carried. AI
  Activity rows carry a destination chip, and the composer's model chip
  shows a small arrow whenever answers come from off this Mac.
- **Cloud Privacy switches** (Settings › AI Assistant › Cloud Privacy):
  one switch per kind of data that background work — email insights,
  thread status, routines, reviews — may send to a cloud model. Journal
  and Wellness are off by default. Held-back work is skipped and shown in
  AI Activity as "kept on this Mac", never dropped silently. Chat is
  never gated. A one-time note explains this the first time you pick a
  model that runs elsewhere.
- **Liabilities in Portfolio.** Mortgages, loans and credit lines, optionally
  secured by a property; net worth headlines the masthead and home card when
  debt exists. Sync-safe like every other portfolio record.
- A `cloud-privacy` help topic for the assistant (and on anjadhe.ai/help).

## Changed

- **Less leaves.** Email bodies lose quoted history, signatures and
  tracking links before background analysis goes to a cloud model, and
  background prompts on a cloud model are capped in size.
- **Anjadhe Cloud card** states its commitments in checkable sentences,
  names DeepInfra as the inference provider under a no-retention
  agreement, and shows the commit the server is running (Connect v1.5.0's
  `/v1/version`) for comparison with the public repository.
- **Models are grouped by where they run** — this Mac, your server, API
  providers, Anjadhe Cloud — in Settings › Models and in the model
  dropdown alike.
