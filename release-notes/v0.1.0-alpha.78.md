# v0.1.0-alpha.78

## Added

- **The assistant can see and use Anjadhe's own window.** Ask "what do you
  see?" or "open Tasks and search for dentist": it takes a screenshot of the
  app, numbers every button and field on it, and works one step at a time —
  click, type, press a key or scroll — looking again after each step. A
  model that can read images sees the screenshot; any other model reads the
  screen as text. Every action asks first. It can never click its own chat
  or answer its own permission prompts, and once it has looked at an email
  or a web page in a chat, every action in that chat asks again.
- **Use other apps (experimental, off by default).** Turn on Settings ›
  Developer › Experimental features › Use other apps and the assistant can
  open and operate other apps on this Mac the same way: your own browser,
  with the accounts you are already signed in to, plus Finder, Numbers, Mail
  and the rest. It asks before working on a website you have not approved,
  and every time before buying, confirming an order, paying, sending,
  deleting or signing in; ordinary clicks, typing and scrolling don't ask.
  It never types passwords or card numbers, never touches Keychain, password
  managers, System Settings or terminal apps, and does not run in background
  routines or from Telegram. macOS asks once for Accessibility (and Screen
  Recording for screenshots), and a Stop bar sits at the bottom of the
  screen while it works. It has not yet been run by a live model on a real
  website, which is why it ships behind the switch.
