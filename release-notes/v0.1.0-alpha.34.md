# v0.1.0-alpha.34

Fixes a launch crash in v0.1.0-alpha.33, which was pulled minutes after
publishing. Everything alpha.33 introduced ships here instead.

## Fixed

- **The app launches again.** alpha.33 shipped without a new module the
  app requires at startup (`llamacpp/embed-manager.js` missed the
  packaging list), so it crashed before drawing a window — which also
  meant the auto-updater couldn't run. If you updated to alpha.33,
  download this version manually; from alpha.34 on, the release pipeline
  verifies every startup module is packaged (and launches the built app)
  before a release counts as published.

## Added

- **Writing Voices** (experimental, off by default — Settings › Developer ›
  Experimental features). Create a named voice — *My voice*, or anyone
  whose writing you have — give it documents (posts, essays, books,
  speeches), and press **Study**: the assistant writes a short, editable
  style guide plus real passages it will imitate. Your edits to the guide
  survive re-studies; pin the passages that carry the voice best. **Draft
  in this voice…** opens a chat already primed to write that way, and the
  draft names the documents it drew on. Everything is indexed on your Mac
  by a small local model; semantic search over your documents is a
  one-time ~330 MB download in **Settings › Writing Voices**. Searching
  opens the matching document right there — full text, terms marked — with
  doors to the original file, and deleting a document moves the file to
  the Trash, never a hard delete.
- **AI Assistant in the sidebar and app switcher.** It sits alone at the
  top, right under Home. If you had hidden the old tile, it comes back
  once — hide it again and that sticks.
- **Email AI: a Connect an account button** on the empty state, so getting
  started doesn't require finding Settings first.

## Changed

- **Connecting a Google account starts the first email and calendar sync
  immediately** — from Settings as well as setup, and when a service is
  toggled back on. No more empty app until you open it.
- **Email AI overview rows open the insight in place** instead of jumping
  into its folder — the nav stays put, and back returns to the overview.
