# v0.1.0-alpha.21

## Added

- **News**: a full news page for the topics you follow. An editorial front
  page (lead story, a Latest rail, a section per topic), a reader that fetches
  and summarizes articles on your Mac, a "Catch me up" digest, and upcoming
  dates spotted in articles offered as "Add to Schedule". The x on any story
  means "show fewer like this" and ranking learns from it; stories boosted
  toward your interests carry a visible "For you" label. Headlines come
  straight from news feeds, never written by the model, and your clicks and
  ranking stay on this Mac. News shares the Discover pane's switch and topic
  list (Settings > Appearance, plus web search enabled).
- **Weather and local news**: add an optional location in the Discover topics
  dialog and the pane shows today's weather (from Open-Meteo) and headlines
  for your area.
- **The `anjadhe` terminal command**: Settings > AI Assistant > Terminal
  Access installs a command that talks to the running app. Bare `anjadhe`
  opens an interactive session; `anjadhe ask "question"` and
  `anjadhe task "goal"` are one-shots. Same brain and same permissions, with
  approvals shown right in the terminal; the transcript lands in a "Terminal"
  conversation that stays on this Mac.
- **Images in chat**: attach images with the + button or drag and drop when
  your model can read them. Vision-capable models carry a "Reads images"
  badge in Settings; screenshots the assistant takes with its tools now reach
  vision models too, and sent thumbnails expand to a lightbox on click.
- **Task mode on the composer**: the mode chip now cycles agent, chatbot, and
  task. In task mode your message becomes a long-running job: planned into
  steps, approved by you, run with tools under safeguards, and reported back.
- **System control for the assistant**: Apple Shortcuts tools, AppleScript
  recipes for controlling apps, and background processes (start, poll, and
  stop long-running commands). Every script still asks permission first.
- **One web search switch**: an explicit "Enable web search" master toggle in
  Settings > AI Assistant > Web Search. Off means nothing in Anjadhe sends
  queries to the web, and every feature honors it.
- **Notes tags**: tag pills on a note are now clickable filters, and a
  "Find a tag" box in the sidebar narrows the tag list as you type.

## Changed

- The assistant panel slides in over the page as a drawer instead of pushing
  your content aside.
- Article links from News and Discover open in the built-in browser's reader
  view by default.
- Anjadhe Connect now identifies your install with a random id instead of one
  derived from the Mac's hostname; existing installs migrate automatically,
  and the Connect card shows the id's anonymous hash for support.
- The in-app help guide was refreshed for all of the above and now matches
  the current Settings layout.

## Fixed

- Security hardening: closed a shell-approval bypass via AppleScript and
  tightened how image data URLs are rendered.
- MCP tool servers that need `npx` (like the browser) now start correctly
  when Anjadhe is launched from Finder, and `run_command` finds Homebrew and
  nvm tools in the same situation.
- Vision model downloads use the correct file names with sha256 pins, and
  vision adapter files no longer appear as installable models.
- Email compose: the AI Assist panel could sit below the window edge.
- Sharing your model on the network: a watchdog now keeps the shared server
  alive.
