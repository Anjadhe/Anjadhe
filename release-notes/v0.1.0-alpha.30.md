# v0.1.0-alpha.30

Decisions: the plans you settle with the assistant stop evaporating into
chat history — plus a speed fix for Goals and sturdier links in briefings.

## Added

- **Per-record decisions.** A decision is a dated instruction pinned to
  one specific record: a strategy's "invest $2,000 monthly through
  October, split 60/40", a task's "never move this past Friday". Settle
  one in chat and the assistant asks before saving it (you'll see a
  quiet "Noted on …" confirmation); from then on it re-reads that
  decision every time it touches the record, in any conversation, so a
  plan made in one chat governs the next. Every record that can carry
  decisions shows them on its page — the task editor, goal details,
  strategy details, a portfolio account, a routine — where you can also
  add or delete them by hand. Decisions sync between your Macs. Chats
  that read untrusted content (web pages, incoming email) can neither
  read nor write them.

## Fixed

- **The Goals page is fast again.** Opening a goal with a long task
  list re-read the whole schedule from storage once per task — and the
  page's nav and cards repeated the work per goal. It now reads once.
- **Task links in briefings survive a mistyped link.** A routine's
  briefing sometimes cited tasks whose links rendered as dead
  underlined text because the model wrote the link URL slightly wrong.
  The common misspellings are now understood, and a link that still
  can't be understood keeps its original form recorded so it can be
  diagnosed.
- The titlebar Back button's arrow icon now actually renders alongside
  the name of where you came from (it silently fell back to the house
  icon before).
- The Morning News routine can reach your News feed again — its digest
  is grounded in the headlines you follow instead of a plain web
  search.
