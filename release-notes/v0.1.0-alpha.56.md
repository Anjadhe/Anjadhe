# v0.1.0-alpha.56

## Added

- **Chat with your Mac's assistant from Telegram.** Create your own bot
  with @BotFather, paste its token in Settings › Accounts › Telegram,
  and link one chat with a pairing code — messages from that chat run on
  your Mac's assistant and reply in place. One chat only, your own bot
  only, and message text is never logged. An optional toggle mirrors
  the Mac's reminders and notices to the linked chat, each under a
  bold "Anjadhe · Reminder" (or Task, Routine, Email) header so it never
  reads like a reply.
- **The Assistant is now the phone's home tab.** Chat from your phone
  runs on the paired Mac's brain over the same encrypted channel sync
  uses; the conversation syncs back, so a dropped connection loses
  nothing. New phone screens for Email AI, Projects, News, Portfolio
  and Wellness ride along.
- **Phone sync goes direct at home.** On your home network the phone
  now talks straight to the Mac (the Mac runs its own small relay); the
  hosted relay is the fallback for everywhere else. The Sync screen
  names which path is in use.

## Changed

- Big read-everything jobs in task mode (a sweep over many emails or
  files) now run a few passes at once on engines that can take it —
  same results, less waiting.
- Desktop notifications route through one funnel, so reminders, task
  moments and priority-email notices all behave the same (and forward
  to Telegram when linked).

## Fixed

- An email that states an exact offset ("renews in 30 days") now gets
  its real date, resolved from the email's own date — while vague
  windows ("3-5 business days") correctly stay dateless.
