# v0.1.0-alpha.20

## Fixed

- **Email insight notifications match what's in the app.** The "New insight
  from..." notification used to fire the moment a new email was flagged for
  analysis, before the AI had looked at it, so emails the AI then judged not
  worth surfacing produced notifications with no insight behind them. The
  notification now fires only when an insight is actually saved, so clicking
  through always finds the matching card in the Insights list and home feed.
  It arrives a little later than before, once the analysis has really run.
