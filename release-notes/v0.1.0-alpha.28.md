# v0.1.0-alpha.28

The release where the AI story got honest about small Macs. Local models
below 32 GB of memory never worked well enough to stand behind, so they are
no longer offered — and the new Anjadhe Cloud is the suggested brain for
those machines instead. The first-run wizard was rewritten around that
story, in plain language a person would actually say. Alongside it:
recurring events landed in Calendar, and every detail page grew a door to
the assistant.

## Added

- **Anjadhe Cloud** — an open-weight model hosted by Anjadhe, for Macs that
  can't run a capable model locally: no account, no key, a free monthly
  allowance of 1,000 AI requests while it's in preview. What runs on it goes
  to Anjadhe's server, then to an inference provider under a no-retention
  agreement, without your identity — nothing is stored, nothing is used to
  train models, and the service's source code is public so that can be
  checked. Never a default or a fallback: it exists only if you add it.
- **Recurring events in Calendar.** The event form has a Repeat row (daily,
  weekdays, weekly, monthly, yearly), editing an occurrence asks whether the
  change is for that event or the whole series, and the event detail says how
  the series repeats. Deleting already asked; editing now does too.
- **"Ask about this…" everywhere.** Task, goal, calendar-event, open-email,
  and email-insight details all carry a pill that opens the assistant with
  that record as context and the composer empty — you ask your own question,
  nothing is pre-written for you.
- **Executed trades in email become portfolio transactions.** A brokerage
  confirmation's trades are captured with the insight and carry an "Add to
  portfolio" button — the same review dialog as ever; nothing writes itself.
- **Task rows multi-select.** The row checkbox selects; a bulk bar deletes
  with one confirm and one undo. Completing moved into the row menu. The
  assistant can also delete a goal together with its tasks, behind the same
  ask-first permission as every delete.
- **A little confetti** when you complete a task.

## Changed

- **Local models are no longer offered below 32 GB of memory.** The small
  models that fit 8–16 GB Macs didn't work well enough, and offering a model
  that disappoints is worse than offering none. Macs under 32 GB are offered
  Anjadhe Cloud first — with a server you own or your own OpenAI/Anthropic
  key as the other homes — in first-run setup and in Settings alike.
  Existing installs keep any small model they already added.
- **The first-run wizard now explains Anjadhe the way a person would.** The
  welcome page introduces a blank canvas with an assistant you can talk to
  and three concrete things to ask it; the model step opens with "a large
  language model is your assistant's brain, and where it runs is where your
  data goes"; the storage step says plainly that there is no remote
  database, that your data isn't our product, and that the source code is
  public.
- **Add a model is a full page** (was a modal): the homes for the model on
  the left — each naming where your data goes — and the chosen step beside
  them.
- **The model list says "Local"** for models on this Mac, instead of naming
  the engine.

## Fixed

- **A stranger who learns a Mac's routing id can no longer evict it** from
  the mobile-sync relay. A connected Mac's slot is now only replaced by a
  reconnect proving it holds the same key; knowing the id alone was enough
  before.
- **Anjadhe Cloud replies report the product model name**, not whichever
  open-weight model the service happens to run upstream.
