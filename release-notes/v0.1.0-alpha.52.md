# v0.1.0-alpha.52

Read the release notes before you restart for an update.

## Added

- **The update card links to the release notes.** When a new version has
  downloaded, the "Update ready" card on the home page now carries a
  "See what's in this release" link. It opens that version's notes from
  the public changelog at anjadhe.ai, so you can see what changed and
  decide whether to restart now or let it install on your next quit.
  Offline, it points you at the changelog page instead.
