# v0.1.0-alpha.84

## Changed

- **The assistant can tell an old note from a current one.** Reading your
  notes now carries the date each one was last changed. Asked something two
  notes disagree about — an address that moved, a code that was reissued —
  it can lead with the newer one and say the older still reads differently,
  instead of quoting whichever it happened to find first.

## For the curious

The workroom preview (Settings › Developer › Experimental features; off by
default, still unfinished) got four fixes, all found by reading one live
run's own log.

- **Looking at the browser no longer stops the work.** Bringing the agent's
  Chrome window forward to watch used to pause the team and cost the agent
  its whole job. Watching is now free; a click or a keystroke meant for the
  page is what hands you the wheel, and the click that merely raises the
  window does not count. The chat also stopped announcing "you have control
  of Chrome" for things you never did, like the agent's own tab closing.
- **An agent that can no longer see what it read says so.** A long job
  shortens its older findings to make room, and that shortening used to keep
  the preamble and throw the facts away — so an agent that had read your
  calendar twenty times finished with nothing but boilerplate and wrote up
  two meetings that do not exist. What is kept is now whole, what is dropped
  says it was dropped, and small readings are not shortened at all. An agent
  that asks the same question three times and gets the same answer now stops
  instead of spending the job.
- **Two new agents.** **Notes** reads what you wrote down, and **Planner**
  sees your calendar and your tasks together — because an empty calendar
  with six things due is not a free day, and neither half could see that
  alone.
